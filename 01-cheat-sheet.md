# 1️⃣ Python Cheat Sheet

## Common Methods

| Concept | What It Does | Example |
|----------|-------------|----------|
| `[::-1]` | Reverse string/list | `"hello"[::-1]` → `"olleh"` |
| `.append()` | Add item to list | `[1,2].append(3)` |
| `.pop()` | Remove last item | `[1,2,3].pop()` |
| `.insert(pos, item)` | Insert item | `[1,3].insert(1,2)` |
| `.lower()` | Lowercase | `"HI".lower()` |
| `.upper()` | Uppercase | `"hi".upper()` |
| `set()` | Remove duplicates | `set([1,1,2])` |
